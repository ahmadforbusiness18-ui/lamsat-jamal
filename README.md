# Lamsat Jamal — Palestinian embroidery store
React + Vite + Tailwind + Framer Motion.

    npm install
    npm run dev

- Brand, tagline, products, currency rates, testimonials: `src/data.js`
- Real photos: put files in `public/photos/` and set `image: '/photos/name.jpg'` on a product
- Checkout is a UI demo (no payment is taken). Connect Stripe / Apple Pay before selling.
